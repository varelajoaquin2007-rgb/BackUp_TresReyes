# 🚚 Tres Reyes Logística

> Sistema de gestión y seguimiento para servicios de logística y envíos.

---

## 📝 Descripción
**Tres Reyes Logística** es una plataforma web desarrollada para la gestión eficiente de operaciones logísticas, control de paquetes, administración de rutas y seguimiento de envíos en tiempo real.

---

## ✨ Características Principales
* **Gestión de Envíos:** Registro, actualización y seguimiento del estado de los paquetes.
* **Panel de Administración:** Control centralizado de clientes, envíos y logística operativa.
* **Calculadora / Cotizador:** Herramienta para estimar costos de envío según origen, destino y peso/volumen.
* **Diseño Responsive:** Interfaz adaptada para dispositivos móviles y escritorio.

---

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap / Tailwind)
* **Backend:** PHP / Node.js *(A confirmar)*
* **Base de Datos:** MySQL *(A confirmar)*
* **Despliegue / Hosting:** Hostinger / InfinityFree
